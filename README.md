# Personal Life Planner — V0.1

این نسخه یک PWA آفلاین‌محور برای iPhone است.

## امکانات فعلی
- Today
- Quick Add
- Tasks با سقف ۶ مورد در روز
- Habits + Habit Logs
- Events
- Journal
- Expenses
- Categories و Payment Sources
- Calendar
- Historical Day / Timeline
- Search
- Basic Insights
- Export / Import JSON
- Offline cache / Add to Home Screen

## نصب روی iPhone
این پروژه باید روی یک آدرس HTTPS میزبانی شود تا Service Worker و نصب PWA فعال شوند.
بعد از انتشار روی GitHub Pages:
1. لینک سایت را با Safari روی iPhone باز کن.
2. Share را بزن.
3. Add to Home Screen را انتخاب کن.
4. آیکون Personal Life Planner روی Home Screen ظاهر می‌شود.

## نکته
داده‌های V0.1 در IndexedDB خود دستگاه ذخیره می‌شوند. قبل از پاک‌کردن Safari یا جابه‌جایی دستگاه، از Settings > Export Backup خروجی JSON بگیر.
